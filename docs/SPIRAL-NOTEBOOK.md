# 스프링 줄공책과 본문 전환

아이보리 본문에 가로줄과 여백선을 넣고 왼쪽 고리와 구멍은 책 외곽에 고정했다. 850px부터 왼쪽 목차와 활성 장을 함께 본다. 자유 입력의 글줄 높이와 배경 타일 높이는 같은 rem 단위다. 손글씨는 기존 Nanum Pen Script, 조작·동의·오류 문구는 시스템 서체다.

## 동작과 변경 파일

| 파일 | 역할 |
|---|---|
| `BookLayout.tsx`, `useSavedNavigation.ts` | 목차·이전/다음·저장 성공 후 이동 직전에 출발 본문을 확보한다. 저장 실패에는 전환이 없다. Participant, 직원별 초안, 구독 및 단일 Outlet은 유지한다. |
| `pageMirror.ts` | 현재 뷰포트와 종이의 교차 영역을 읽는다. 입력의 value·내부 스크롤, 선택 레이블, 동의 체크를 비대화형 복제본에 반영한다. 화면 밖 본문은 자리만 남긴다. hidden input, 비밀번호, 로그인·관리자, 대화상자는 제외한다. 이미 로드된 이미지의 픽셀만 복제한다. |
| `bookTurn.ts` | 정방향에서는 출발 장이 걷히고 역방향에서는 목적지 본문이 돌아와 덮인다. 실제 목적지 HTML은 한 번만 마운트한다. 전환당 텍스처 한 장, 역방향일 때 DOM 복제본 최대 두 장이다. |
| `rasterPaper.ts` | html-to-image 1.11.13으로 보이는 영역만 래스터화한다. 로드된 자체 호스팅 폰트를 포함하고 빈 캡처를 검사한다. DPR 상한 1.5, 최대 180만 픽셀·한 변 2048px다. 공유 캐시는 공개 글꼴에만 사용한다. |
| `graphics/pageCurl.ts`, `pageCurlShape.ts`, `service.ts` | 공용 렌더러의 52×6 분할 곡면에 본문과 줄을 같은 UV로 매핑한다. 앞면은 sRGB, 뒷면은 불투명 아이보리다. 실제 첫 렌더 뒤 DOM 복제본을 감춘다. 일회용 컬 canvas에만 종료 시 컨텍스트 반환을 적용한다. |
| `book.css`, `preferences.tsx`, `MotionDiagnostics.tsx`, `Participant.tsx`, `Forest.tsx` | 스프링, 종이, 입력 기준선, 모션 정책 안내, 행사 권한과 목적지 준비 상태의 변경을 연결한다. |

준비 예산은 720ms, 실제 재생은 640ms다. 브라우저가 긴 동기 작업을 실행하는 동안에는 타이머도 늦어질 수 있다. 폰트 준비 지연, 캡처 거절, 초기 그래픽 오류에는 같은 내용의 DOM 3D 전환을 사용한다. 준비 중인 목적지, 안전하게 복제할 수 없는 미디어, 마음 트리 입·퇴장, 동작 줄이기와 페이지 효과 끄기는 즉시 이동한다. 같은 행사 코너의 힌트·라운드·권한 변경도 즉시 반영한다. 전환 중 컨텍스트 손실, 인증 변경, 새 이동에서 관련 세션과 임시 자료를 정리한다. 초안 복원은 기존 provider가 담당한다.

## 검증 재현

로컬 가상 행사 환경에서 `corepack pnpm typecheck`, `corepack pnpm lint`, `corepack pnpm test`, `corepack pnpm build`, `corepack pnpm test:e2e`를 실행한다. 브라우저 추가 검증은 `corepack pnpm exec playwright test page-curl --browser=webkit`으로 실행한다. 전체 E2E는 로컬 테스트 데이터를 변경한다.

- `page-curl.spec.ts`는 제목과 실제 입력한 가상 답변, 점심시간 선택 및 동의 상태로 양방향 0·25·50·75·100%를 캡처한다. 실제 시작·끝과의 픽셀 차이, 중간 프레임의 변화, 열린 영역의 목적지 일치, 체크와 화살표의 표시를 검사한다. 재생 위치 제어는 Playwright 테스트 문서에만 설치된다.
- `page-curl-safety.spec.ts`는 여섯 화면 폭, 큰 글자, 긴 설문, 입력기 합성 이벤트 및 키보드 높이 변화, 캡처 지연·실패, 이미지, 민감 필드, 컨텍스트 손실과 모션 정책을 시험한다.
- `page-curl-playback.spec.ts`는 실제 재생 속도로 녹화하고 Chromium에서 20회 이동 후 임시 표면·브라우저 DOM·리스너·JS 힙을 측정한다. JS 힙에는 로드한 모듈과 공개 글꼴도 포함된다. 브라우저 RAF 횟수와 실제 GPU 표시 프레임률은 따로 해석한다.
- [이미지·녹화·측정 JSON](../artifacts/screens/spiral-notebook/)에는 가상 응답만 사용한다. `*-normal.webm`은 준비 상태에 따라 DOM 대체도 포함하고, `*-dom.webm`은 캡처를 차단한 조건이다.

## 실제 휴대폰 확인

운영에서 확인할 때는 [공책 확인용 로그인](https://mck1025.github.io/Year_END_Party_Website/?motionDebug=1#/login)을 연다. 로컬 재현에는 두 기기에서 접근할 수 있는 같은 테스트 빌드와 가상 계정을 사용한다. 설정을 유지한 채 같은 질문의 답변·선택·동의를 채우고 다음 장과 이전 장을 확인한다. 동작 줄이기가 켜진 기기는 바로 이동한다. 긴 설문 하단에서 한글을 입력하면서 목차를 누르고 돌아와 초안·선택값을 확인한다. 테스트 빌드 해시 앞 `?motionDebug=1`에서 표시 방식·취소 사유를 복사할 수 있다. 실제 iPhone·Android 키보드, 인앱 브라우저 및 GPU 속도는 이 브라우저 시험과 별도로 확인해야 한다.
