# 행사 운영자 설명서

## 행사 전

1. `/#/admin`에서 운영자 이메일·비밀번호로 로그인합니다. TOTP를 등록했다면 인증 앱 번호도 입력합니다.
2. **설정·내보내기**에서 행사일과 개인정보 삭제 예정일을 설정합니다. 공개 시작은 해당일 18:00 한국시간이며, 그때 자동으로 모든 내용을 공개하지 않습니다. 이후 진행 버튼은 운영자가 누릅니다.
3. 회사 로고를 올립니다. 사진 형식 JPG/PNG/WebP, 최대 8MB입니다. 로고는 인증된 직원의 대기실에 표시됩니다.
4. **사원 관리**에서 UTF-8 또는 엑셀 CSV(ANSI/CP949)를 올리고 미리보기를 확인한 뒤 등록합니다. 헤더는 `employee_no,name,department,date_of_birth`이며 날짜는 YYYY-MM-DD입니다. 열 제목 아래에 직원 데이터가 한 줄 이상 있어야 하고 사번은 중복할 수 없습니다. 읽을 수 없는 파일을 선택하면 이전 미리보기도 비워 잘못된 명단 등록을 막습니다.
5. **직원 한 명 추가**에서 사번·이름·부서·생년월일을 입력해 개별 등록할 수 있습니다. 직원 로그인에는 이름이나 발급 코드 없이 생년월일 6자리(YYMMDD) 비밀번호만 입력합니다. 예: 1990-01-01 → `900101`. 사번과 활성 직원의 생년월일 6자리 중복은 서버에서 거절합니다. CSV로 생년월일을 수정하면 비밀번호가 바뀌고 기존 로그인 연결이 해제됩니다.
6. 직원 행을 펼쳐 **직원 삭제**를 누르고 확인하면 해당 직원의 설문·추천·출제 정보와 로그인 연결을 영구 삭제합니다. 다른 직원의 명단은 유지됩니다. 이미 공개된 내용과 되돌리기/리허설 기록에서 삭제된 직원 정보가 다시 나오지 않도록 행사 화면을 대기실로 돌리고, 취향 통계를 비워 재검수를 요구합니다. 익명 글은 작성자 연결이 없어 개별 직원 삭제로 제거하지 않습니다.
7. 직원에게 로그인 주소와 설문 마감일을 안내합니다. 실제 명단·사진은 GitHub에 올리지 않습니다.

## 설문과 공개 콘텐츠 검수

**질문 관리**에서 질문과 선택 항목·활성 여부를 바꿀 수 있습니다. 응답 수집 중 문항을 바꾸면 직원에게 재확인을 안내합니다.

직원 설문의 질문별 공개 제외 체크박스는 표시하지 않습니다. 전체 공개 활용 동의와 관리자 검수는 유지합니다. 기존 응답에서 직원이 명시적으로 제외했던 문항은 숨겨진 UI 변경으로 동의를 확대하지 않도록 그대로 보존합니다.

**설문·추천**에서 제출·미작성 현황과 직원별 전체 답변, 최종 추천 한 표를 확인합니다. 공개 이유에는 추천자를 알아볼 수 있는 내용이 없는지 확인하고 승인합니다. 득표가 동률이면 공동 수상, 유효 표가 0개면 수상자 없음입니다.

**인물 맞히기**에서 공개에 동의한 직원과 공개 제외되지 않은 답변만 선택합니다. 1~3개를 고른 순서대로 힌트를 편집하고, 공개 검수에 체크한 뒤 저장합니다. 순서 숫자를 수정해 문제 순서를 바꿉니다. 직원이 답변·동의를 수정하면 승인이 해제되므로 다시 검수합니다. 공식 진행 중인 문제는 대기실로 돌아간 뒤 수정합니다.

**1년 회고**에서 사진·문구·순서를 등록하고 게시 동의를 확인한 카드만 공개로 체크합니다. 회고 단계에 들어가면 직원이 휴대폰에서 직접 스크롤해 확인합니다.

**취향 통계**에서 질문을 선택해 실제 응답을 자동 집계합니다. 자유 입력의 같은 뜻을 합칠 때는 항목과 인원을 조정합니다. 확인 후 승인합니다. 비동의·공개 제외·비활성 직원의 응답은 자동 집계에서 빠집니다. 설문을 마감한 후 최신 응답으로 다시 집계하고 승인하는 것이 좋습니다.

## 혜성식품 대나무숲

직원 메뉴 **대나무숲**에서 바라는 점·고마운 점·아쉬운 점을 익명으로 남기고 다른 직원의 글을 읽습니다. 게시글에는 본문·분류·작성일·게시글 번호만 저장하며 작성자의 직원/계정 ID·이름·소속·정확한 작성 시각은 저장하지 않습니다. 로그인한 직원만 이용하며, 스팸 방지를 위한 하루 제출 횟수(최대 10회)는 게시글과 연결되지 않는 별도 비공개 카운터로 관리하고 다음 날 정리합니다. 새 글 확인과 이전 글 더 보기를 제공합니다.

관리자 **대나무숲** 메뉴에서도 작성자 정보 없이 글만 조회하며, 개인정보 노출·비방 글을 확인 후 삭제할 수 있습니다. 본문으로 신원이 추측될 수 있으므로 직원에게 식별 정보를 쓰지 않도록 안내합니다. 서비스 제공자의 네트워크/보안 로그까지 무기록을 보장하는 기능은 아닙니다. 행사 종료 후 전체 개인정보 파기는 익명 글과 제출 횟수도 함께 삭제합니다.

## 리허설

**리허설** 탭에서 미리 승인한 직원 한 명의 문제를 선택하고 시작합니다. 다음 힌트 → 정답 → 초기화를 연습합니다. 이 화면의 미리보기만 바뀌며 공식 직원 화면·추천·공식 집계에는 영향을 주지 않습니다. 실제 직원의 휴대폰으로도 공식 대기실이 그대로인지 확인합니다.

## 행사 당일

- [ ] 운영자 기기 충전, 와이파이·모바일 데이터 점검.
- [ ] 행사일·한국시간 18시·삭제일 설정 확인.
- [ ] 사원 수·설문·추천·공개 동의·문제·사진·통계 검수 확인.
- [ ] 직원 한 명으로 실제 모바일 접속·새로고침 복구 확인.
- [ ] 회고·인물·취향·시상·엔딩 문구 최종 확인.
- [ ] 직원들에게 화면이 자동으로 바뀐다는 점과 인물 정답은 서로 말로 추측한다는 점 안내.

18시 이후 **실시간 진행**에서 아래 순서로 진행합니다.

1. 다음 순서 · 1년의 장면들 → 확인.
2. 다음 순서 · 이 사람, 누구일까요? → 인물 선택 → 이 인물로 시작.
3. 다음 힌트 공개를 한 번씩 누릅니다. 이미 공개된 힌트는 모두 남습니다.
4. 정답 공개 → 확인. 다음 인물 또는 현재 인물 다시 시작을 선택합니다.
5. 다음 순서 · 우리의 취향 → 승인된 질문 선택 → 질문 먼저 공개 → 대화 후 결과 공개.
6. 설정에서 추천을 마감합니다. 다음 순서 · 고마운 동료를 누르면 실제 유효 표의 공동 1위를 포함한 수상자가 공개됩니다.
7. 다음 순서 · 다음 한 걸음으로 엔딩을 공개합니다.

실수했으면 일시 정지 후 확인합니다. 직전 진행 되돌리기는 화면을 이전 상태로 돌리지만 이미 본 정보를 회수하지는 못합니다. 설문·추천·직원·문제·통계·공개 검수가 변경되면 이전 내용의 복원을 막기 위해 직전 되돌리기도 무효화됩니다. 대기·초기화는 설문이나 표를 삭제하지 않습니다. 다른 관리자와 동시에 누르면 한 명만 성공하며, 다른 화면은 새로고침 후 다시 진행해야 합니다.

## 연결 문제

직원 화면의 연결 표시를 확인합니다. 연결이 끊기면 자동 재연결하며 20초마다 서버 상태를 다시 확인합니다. 앱을 다시 열거나 네트워크가 복구되면 즉시 재조회합니다. 계속 실패하면 새로고침하거나 다시 본인 확인합니다. 권한이 취소된 직원은 서버가 조회를 차단합니다.

## 종료

설정에서 필요한 결과를 CSV 또는 엑셀로 내려받습니다. 파일에는 개인 답변과 추천자가 포함되므로 제한된 위치에 보관합니다. 직원 접속 허용을 끄고 [개인정보 파기 안내](PRIVACY-DELETION.md)에 따라 삭제합니다. 사용한 실제 휴대폰·운영용 다운로드 폴더도 함께 정리합니다.
