# 행사 운영자 설명서

## 행사 전

1. `/#/admin`에서 운영자 이메일·비밀번호로 로그인합니다. TOTP를 등록했다면 인증 앱 번호도 입력합니다.
2. **설정·내보내기**에서 **행사일**과 **행사 시작 시각 (한국시간)**을 선택하고 **설정 저장 → 확인**을 누릅니다. 시각은 분 단위로 바꿀 수 있습니다. 실시간 진행 화면에서 일정을 확인하고, 그 시각부터 **다음 순서**를 눌러 콘텐츠를 공개합니다. 개인정보 삭제 예정일은 별도로 설정합니다.
3. 회사 로고를 올립니다. 사진 형식 JPG/PNG/WebP, 최대 8MB입니다. 로고는 인증된 직원의 대기실에 표시됩니다.
4. **사원 관리**에서 UTF-8 또는 엑셀 CSV(ANSI/CP949)를 올리고 미리보기를 확인한 뒤 등록합니다. 헤더는 `employee_no,name,department,date_of_birth`이며 날짜는 YYYY-MM-DD입니다. 열 제목 아래에 직원 데이터가 한 줄 이상 있어야 하고 사번은 중복할 수 없습니다. 읽을 수 없는 파일을 선택하면 이전 미리보기도 비워 잘못된 명단 등록을 막습니다.
5. **직원 한 명 추가**에서 사번·이름·직책·생년월일을 입력해 개별 등록할 수 있습니다. 직원 로그인에는 이름이나 발급 코드 없이 생년월일 6자리(YYMMDD) 비밀번호만 입력합니다. 예: 1990-01-01 → `900101`. 사번과 활성 직원의 생년월일 6자리 중복은 서버에서 거절합니다. CSV로 생년월일을 수정하면 비밀번호가 바뀌고 기존 로그인 연결이 해제됩니다.
6. 직원 행을 펼쳐 **직원 삭제**를 누르고 확인하면 해당 직원의 설문·추천·출제 정보와 로그인 연결을 영구 삭제합니다. 다른 직원의 명단은 유지됩니다. 이미 공개된 내용과 되돌리기/리허설 기록에서 삭제된 직원 정보가 다시 나오지 않도록 행사 화면을 대기실로 돌리고, 취향 통계를 비워 재검수를 요구합니다. 이야기 트리의 비공개 소유자 연결도 삭제되지만, 공개된 익명 글 본문은 남습니다.
7. 직원에게 로그인 주소와 설문 마감일을 안내합니다. 실제 명단·사진은 GitHub에 올리지 않습니다.

## 설문과 공개 콘텐츠 검수

**질문 관리**에서 질문과 선택 항목·활성 여부를 바꿀 수 있습니다. 응답 수집 중 문항을 바꾸면 직원에게 재확인을 안내합니다.

직원 설문에는 동의 체크박스를 표시하지 않으며 답변만 작성해 저장합니다. 저장 즉시 관리자에게 등록되지만 직원들에게 자동 공개되지는 않습니다. 관리자가 검수·승인한 답변만 인물 퀴즈·인물 카드에 공개합니다. 기존 응답의 공개 제외 항목은 보존하며 승인 대상에서 제외합니다.

**설문·추천**에서 제출·미작성 현황과 직원별 전체 답변, 최종 추천 한 표를 확인합니다. 공개 이유에는 추천자를 알아볼 수 있는 내용이 없는지 확인하고 승인합니다. 득표가 동률이면 공동 수상, 유효 표가 0개면 수상자 없음입니다.

**인물 맞히기**에서 설문을 등록한 직원과 공개 제외되지 않은 답변을 선택합니다. 직원을 선택하면 공개 가능한 질문 최대 6개와 공개 승인 체크가 기본 선택됩니다. 필요 없는 질문은 해제하고 힌트를 확인한 뒤 문제 저장으로 확정합니다. 기존 문제의 질문 선택은 유지됩니다. 다음 힌트 공개 때마다 질문과 답변이 함께 한 개씩 나타납니다. 아직 공개하지 않은 답변과 정답 인물은 직원에게 전송하지 않습니다. 순서 숫자로 문제 순서를 바꿉니다. 직원이 답변을 수정하면 승인이 해제되므로 다시 검수합니다. 공식 진행 중인 문제는 대기실로 돌아간 뒤 수정합니다.

**1년 회고**에서 **새 Moment 추가**를 선택하고 제목과 표시 순서를 입력합니다. 대표 사진은 **대표 사진 업로드** 또는 **등록된 사진 선택**으로 지정합니다. **전체 보기**는 사진 전체를 담고, **화면 채우기**는 가로·세로 위치를 조정할 수 있습니다.

**상세 장면 추가** 후 해당 행을 펼쳐 사진·제목·설명·날짜를 입력합니다. **앞으로 / 뒤로**로 장면 순서를 정합니다. **편집 중인 Moment 미리보기**로 확인하고 **Moment 저장**을 누르세요. 새 Moment의 공개 체크는 기본 선택이며 해제하고 저장하면 비공개가 됩니다. **저장된 전체 회고 미리보기**로 공개될 순서를 확인하고 **오프닝 다시 보기**로 책 펼침을 재생할 수 있습니다.

기존 회고 한 항목은 하나의 Moment로 열립니다. 기존 사진은 상세 장면에 있고 대표 사진은 직접 고릅니다. 직원은 행사 중 **1년 회고**에서 공개한 장면을 버튼이나 좌우 스와이프로 넘깁니다. 행사 종료 후 **자유 관람 홈**에서는 앨범이 보이는 동안 6초마다 다음 장으로 넘어가며 마지막 장에서 처음으로 돌아갑니다. **일시 정지**와 **자동 재생**으로 재생을 조절할 수 있고 버튼과 스와이프도 사용할 수 있습니다. 동작 줄이기나 페이지 효과 끄기가 켜져 있으면 수동으로 시작합니다. 두 화면은 같은 브라우저 탭에서 각각 마지막으로 본 장면을 기억합니다.

**취향 통계**에서 질문을 선택해 실제 응답을 자동 집계합니다. 자유 입력의 같은 뜻을 합칠 때는 항목과 인원을 조정합니다. 자동 집계 결과 화면에서는 공개 승인 체크가 기본 선택됩니다. 집계만으로는 승인되지 않으며 **검수 결과 저장**으로 확정합니다. 공개 제외 항목과 비활성 직원의 응답은 자동 집계에서 빠집니다. 저장된 응답을 집계해 관리자가 승인해야 결과를 공개할 수 있습니다. 설문을 마감한 후 최신 응답으로 다시 집계하고 승인하는 것이 좋습니다.

## 혜성식품 이야기 트리

기본은 직원 한 명당 메시지 한 개입니다. **설정·내보내기 → 이야기 트리 → 이야기 트리 여러 메시지 작성하기**를 체크하면 작성 기간에 여러 개를 남길 수 있습니다. 체크하거나 해제하는 즉시 적용됩니다. 다시 해제해도 이미 보낸 글은 모두 보관되며 작성 기간에는 수정·삭제할 수 있습니다. 한 개 제한에서는 내 글을 모두 삭제하면 새 메시지를 작성할 수 있습니다.

직원 메뉴 **이야기 트리**에서 바라는 점·고마운 점·아쉬운 점을 익명으로 남깁니다. 사전에는 내가 보낸 글만 보이며, 다른 직원의 글은 관리자가 공개 트리를 승인해 공개한 뒤에만 읽습니다. 공개 게시글에는 본문·분류·작성일·게시글 번호만 포함됩니다. 같은 직원으로 다른 기기에서 로그인해도 내 글을 관리하도록 별도 비공개 소유자 테이블에 직원 ID와 글 번호를 연결합니다. 직원 공개 조회와 관리자 화면/API에는 소유자 정보가 제공되지 않습니다. DB 운영 권한을 가진 사람은 비공개 연결에 접근할 수 있으므로 완전한 무기록 익명을 뜻하지 않습니다. 로그인한 직원만 이용하며, 스팸 방지를 위한 하루 제출 횟수(최대 10회)는 게시글과 연결되지 않는 별도 비공개 카운터로 관리하고 다음 날 정리합니다. **내가 보낸 마음**에서 기존 글과 분류를 확인·수정·삭제합니다. 삭제 확인은 취소할 수 있으며, 확정하면 복구되지 않습니다. 다시 확인과 이전 글 더 보기도 제공합니다. 수정은 새 글 제출 횟수를 차감하지 않습니다. 기존에 소유자 연결 없이 작성된 글은 사후에 작성자를 추정하지 않아 내 글 수정 대상에서 제외됩니다.

관리자 **이야기 트리** 메뉴에서도 작성자 정보 없이 글만 조회하며, 개인정보 노출·비방 글을 확인 후 삭제할 수 있습니다. 본문으로 신원이 추측될 수 있으므로 직원에게 식별 정보를 쓰지 않도록 안내합니다. 서비스 제공자의 네트워크/보안 로그까지 무기록을 보장하는 기능은 아닙니다. 행사 종료 후 전체 개인정보 파기는 익명 글·소유자 연결·제출 횟수도 함께 삭제합니다.

## 리허설

**리허설** 탭에서 미리 승인한 직원 한 명의 문제를 선택하고 시작합니다. 다음 힌트 → 정답 → 초기화를 연습합니다. 이 화면의 미리보기만 바뀌며 공식 직원 화면·추천·공식 집계에는 영향을 주지 않습니다. 실제 직원의 휴대폰으로도 공식 대기실이 그대로인지 확인합니다.

## 행사 당일

- [ ] 운영자 기기 충전, 와이파이·모바일 데이터 점검.
- [ ] 행사일·시작 시각(한국시간)·삭제일 설정 확인.
- [ ] 사원 수·설문·추천·인물 카드·문제·사진·통계 검수 확인.
- [ ] 직원 한 명으로 실제 모바일 접속·새로고침 복구 확인.
- [ ] 회고·인물·취향·시상·엔딩 문구 최종 확인.
- [ ] 직원들에게 화면이 자동으로 바뀐다는 점과 인물 정답은 서로 말로 추측한다는 점 안내.

**실시간 진행 → 행사 시작 · 응답 마감**을 누르고 확인하면 설문·추천·이야기 트리의 신규 작성·수정·삭제가 즉시 마감됩니다. 일시 정지·대기실 복귀·되돌리기·리허설은 응답 허용 설정을 변경하지 않습니다. 직원은 마감 후에도 본인 제출 내용을 확인할 수 있습니다. 추천 이유는 앞뒤 공백을 제외하고 10자 이상 300자 이하로 작성해야 제출·수정할 수 있습니다. 추천 탭에 다시 들어가면 **이미 추천하였습니다.**와 최종 추천이 표시되며 수정 허용 기간에는 **추천 수정하기**로 변경합니다.

행사를 연기해 설문·추천을 다시 받으려면 **설정·내보내기**에서 행사일과 시작 시각을 **현재보다 미래**로 변경합니다. **설문 수정 허용**, **동료 추천·변경 허용** 중 필요한 항목을 체크하고 **설정 저장 → 확인**을 누르세요. 설문과 추천은 날짜만 바꾸면 자동으로 다시 열리지 않습니다. 허용한 응답은 이미 접속 중인 직원 화면에도 반영되고 새 시작 시각에 다시 잠깁니다. 서버가 저장 시각을 검사하므로 오래 열린 화면에서도 마감 후 저장할 수 없습니다. 기존 답변·추천과 최초 행사 시작 기록은 보존합니다. 응답을 수정하면 해당 답변의 공개 검수가 취소되므로 행사 전에 다시 검수해주세요.

**이야기 트리**는 행사 시작 후 미래 시각으로 일정을 다시 저장하면 별도 체크 없이 새 글 작성과 본인 글 수정·삭제가 열립니다. 직원은 작성란에서 **익명으로 마음 남기기**를 누르고, **내가 보낸 마음**에서 기존 글을 관리합니다. 다른 기기에서도 같은 계정으로 이용할 수 있습니다. 익명 공개 규칙과 하루 새 글 10회 제한은 유지됩니다. 새 시작 시각이 되면 작성·수정·삭제가 다시 잠기고 열려 있던 삭제 확인창도 닫힙니다. 새 글과 수정한 글은 나중에 관리자가 다시 검수·공개한 트리에 반영됩니다. 일정을 바꾸지 않고 처음 행사 시작 버튼만 누른 경우에는 기존처럼 즉시 마감됩니다.

콘텐츠 공개는 설정한 행사 시작 시각부터 아래 순서로 진행합니다. 자유 관람 이전에 행사일이나 시작 시각을 바꾸면 직원 화면은 대기실로 돌아갑니다. 자유 관람 시작 후에도 미래 시각으로 일정을 저장하면 이야기 수정 페이지에 접근할 수 있도록 대기실로 돌아가고 공개 중인 트리와 결과가 닫힙니다. 접속 중단은 콘텐츠 조회를 차단합니다.

1. 다음 순서 · 1년의 장면들 → 확인.
2. 다음 순서 · 이 사람, 누구일까요? → 인물 선택 → 이 인물로 시작.
3. 다음 힌트 공개를 한 번씩 누릅니다. 이미 공개된 힌트는 모두 남습니다.
4. 정답 공개 → 확인. 다음 인물 또는 현재 인물 다시 시작을 선택합니다.
5. 다음 순서 · 우리의 취향 → 승인된 질문 선택 → 질문 먼저 공개 → 대화 후 결과 공개.
6. 추천은 행사 시작 때 이미 마감됩니다. 다음 순서 · 고마운 동료를 누르면 실제 유효 표의 공동 1위를 포함한 수상자가 공개됩니다.
7. 다음 순서 · 다음 한 걸음으로 엔딩을 공개합니다.
8. 공식 행사를 마치면 **행사 종료 및 자유 관람 시작**을 누릅니다. 확인 창에서 이야기 트리 전체 글의 검수·공개를 확인하고 **확인**을 누르면 직원 화면이 자유 관람 홈으로 이동합니다. 이후 공식 게임의 진행·대기실 복귀·되돌리기는 종료됩니다. 리허설은 별도로 이용할 수 있습니다.

### 혜성식품 인물 카드

**인물 카드** 탭에서 **설문 등록 / 공개 승인 / 검수 대기** 인원을 확인합니다. 새 카드의 공개 가능한 답변은 기본 선택됩니다. 이미 저장한 일부 선택은 유지됩니다. 직원이 저장한 원문을 검수하고 필요 없는 질문을 해제한 뒤 **인물 카드 공개 검수 저장**을 누릅니다. **공개 가능한 답변 모두 선택**으로 여섯 답변을 한 번에 선택할 수도 있습니다. 선택만으로 공개되지는 않습니다. 활성 직원의 비어 있지 않은 답변만 승인할 수 있고 기존 공개 제외 항목은 제외됩니다. 전체 선택을 해제하고 저장하면 공개가 취소됩니다. **설문·추천 → 직원별 원본 조회**에서도 같은 검수를 할 수 있습니다.

답변·공개 제외 항목이나 질문이 바뀌면 관련 승인이 해제되므로 다시 검수해주세요. 직원에게는 승인된 질문과 답변, 이름·직책만 표시됩니다. 설문 미작성 또는 공개 검수를 마치지 않은 직원은 카드 목록에 나오지 않습니다.

자유 관람 홈에서 기존 이야기 트리와 인물 카드를 자유롭게 오갈 수 있습니다. 인물 카드는 공개된 동료의 이름·직책을 한 페이지에 모아 보여줍니다. 이름 검색으로 찾거나 카드를 눌러 질문·답변 상세창을 엽니다. **닫기**, 바깥 영역 터치, Esc로 목록으로 돌아옵니다. 종료 후 재접속하면 홈으로 이동하고, 연결이 끊긴 화면은 재연결 시 최신 종료 상태를 복구합니다. 트리 공개를 취소해도 자유 관람 상태는 유지됩니다.

### 전체 순서 다시 진행

**실시간 진행 → 처음부터 다시 진행 → 확인**을 누르면 자유 관람 종료 후에도 모든 직원 화면이 대기실로 돌아갑니다. 공개 중인 힌트·결과·트리를 닫고, **다음 순서 · 1년의 장면들**부터 다시 진행할 수 있습니다. 설문 답변·추천·이야기 원본·공개 검수·출제 자료와 응답 허용 설정은 보존합니다. 재시작 자체는 직전 진행 되돌리기로 취소할 수 없습니다.

이 버튼은 실제 직원 화면에도 반영됩니다. 직원 화면에 영향을 주지 않는 한 사람 연습은 기존 **리허설** 탭을 사용합니다. 이미 열어 둔 화면에 최신 기능이 없으면 페이지를 새로고침해주세요. 저장된 로그인 정보나 작성 중 초안을 지우는 저장소 초기화는 필요하지 않습니다.

자유 관람 시작 전 진행 실수는 일시 정지 후 확인합니다. 직전 진행 되돌리기는 화면을 이전 상태로 돌리지만 이미 본 정보를 회수하지는 못합니다. 설문·추천·직원·문제·통계·공개 검수가 변경되면 이전 내용의 복원을 막기 위해 직전 되돌리기도 무효화됩니다. 대기·초기화는 설문이나 표를 삭제하지 않습니다. 다른 관리자와 동시에 누르면 한 명만 성공하며, 다른 화면은 새로고침 후 다시 진행해야 합니다.

직책은 기존 `department` 열을 사용합니다. Supabase의 `public.employee_directory.department` 또는 `private.employees.department`에서 수정하면 반대편에도 동기화되어 관리자 명단·직원 명단·인물 카드에 같은 값이 표시됩니다. 일반 직원은 이 값을 변경할 수 없습니다.

## 연결 문제

직원 화면의 연결 표시를 확인합니다. 연결이 끊기면 자동 재연결하며 20초마다 서버 상태를 다시 확인합니다. 앱을 다시 열거나 네트워크가 복구되면 즉시 재조회합니다. 계속 실패하면 새로고침하거나 다시 본인 확인합니다. 권한이 취소된 직원은 서버가 조회를 차단합니다.

## 종료

설정에서 필요한 결과를 CSV 또는 엑셀로 내려받습니다. 파일에는 개인 답변과 추천자가 포함되므로 제한된 위치에 보관합니다. 직원 접속 허용을 끄고 [개인정보 파기 안내](PRIVACY-DELETION.md)에 따라 삭제합니다. 사용한 실제 휴대폰·운영용 다운로드 폴더도 함께 정리합니다.

## 공개 트리 공개

1. **이야기 트리**에서 전체 글을 확인하고 개인정보·비방이 담긴 글을 삭제합니다. 직원에게 작성자 정보는 공개되지 않으며 관리자 게시글 화면에도 표시되지 않습니다.
2. 행사를 시작하고 설정한 시작 시각이 지나면 **공개 트리** 메뉴에서 **전체 글의 개인정보·비방 내용을 검수했습니다**를 체크합니다. 그 전에는 운영자만 미리보기를 볼 수 있습니다.
3. **검수한 전체 글로 트리 공개 → 확인**을 누릅니다. 당시 전체 글이 공개용 사본으로 저장되며 직원 휴대폰이 공개 트리로 이동합니다. 직원이 재접속해도 공개 상태가 복구됩니다.
4. 직원이 양말이나 선물 장식을 누르면 본문이 확대됩니다. 바깥 클릭·Esc·**트리로 돌아가기**로 다시 이야기 장식이 달린 화면으로 돌아갑니다. 한 트리에 최대 30개의 이야기가 달리며 그 이상은 **다음 이야기들 / 이전 이야기들**로 이동합니다. 각각 자유롭게 읽으며 선택은 다른 직원 화면에 영향을 주지 않습니다.
5. **효과 멈추기**로 트리/눈 애니메이션을 멈춥니다. 동작 줄이기 설정은 정지 화면으로 표시하며 WebGL 미지원이나 컨텍스트 손실 때도 그림과 이야기 장식 버튼으로 계속 읽을 수 있습니다.
6. **트리 공개 종료 → 확인**으로 직원 화면을 기존 행사로 복귀시킵니다. 자유 관람 중에는 종료 상태를 유지하며 트리만 닫힙니다. 전체 글의 새 조회는 차단되고 공개 사본은 삭제됩니다. 이미 읽거나 캡처한 내용은 회수되지 않습니다. 다음 행사 진행·대기실 복귀·행사일 변경·사이트 중단도 트리 공개를 종료합니다. 일시 정지·재개는 공개 상태를 유지합니다.

트리 공개는 기존 회고·인물·취향·시상 순서를 덮어쓰지 않습니다. 종료 후 이전 진행을 이어갑니다. WebGL 서비스 구조와 다른 페이지에서 눈 효과를 재사용하는 방법은 `src/graphics/README.md`를 참고하세요.
