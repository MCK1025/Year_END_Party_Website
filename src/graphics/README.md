# 공용 WebGL 서비스

별도 서버가 아니라 브라우저 안에서 실행되는 Three.js 렌더링 서비스입니다. GitHub Pages에서 그대로 동작하며, 페이지가 렌더러를 직접 관리하지 않습니다.

- `service.ts`: 캔버스별 렌더러·카메라·리사이즈·프레임 루프·가시성·동작 줄이기·컨텍스트 손실·종료를 관리합니다. 기기 픽셀 비율은 최대 1.5입니다. 숨겨진 탭/화면 밖에서는 프레임 루프가 멈춥니다.
- `types.ts`: 효과 플러그인(`EffectFactory` → `update`/`dispose`)과 세션 계약입니다.
- `effects/tree.ts`, `effects/snow.ts`: 전구와 낙설을 각각 WebGL 한 번의 그리기 호출로 표시합니다. 눈 크기와 속도는 CSS 픽셀 기준이며, 두 효과는 같은 활성 시간을 사용합니다.
- `christmas.ts`: 두 효과와 초기 정지 상태를 공용 서비스에 전달합니다. 정적인 종이 전나무·전선·쌓인 눈은 `components/tree/PaperFir.tsx`에 있으며 그래픽 초기화 전후에 같은 위치를 유지합니다.
- `palette.ts`: `DESIGN.md`/CSS와 일치하는 WebGL 색상 토큰입니다.

다른 페이지에서 눈만 사용하려면 페이지가 보일 때 동적으로 서비스를 불러오고, 컴포넌트 해제 시 반드시 세션을 종료합니다.

```ts
const session = createGraphicsSession(canvas, [snowfall(canvas)], showStaticFallback);
await session.ready; // GPU 셰이더를 비동기로 준비한 뒤 장식 캔버스를 표시
session.setPaused(true); // 페이지의 효과 멈춤 버튼
session.dispose(); // 컴포넌트 해제 시; 중복 호출에도 안전
```

효과는 자신이 추가한 지오메트리·재질·텍스처를 `dispose`에서 정리해야 합니다. 렌더러를 만들거나 자체 RAF를 시작하지 않습니다. `prefers-reduced-motion`에서는 정지 프레임을 렌더링합니다. 실제 컨텍스트 손실은 DOM/SVG 대체 화면으로 전환합니다. 일반 종료에서 컨텍스트를 강제로 잃게 하지 않아 React의 같은 캔버스 재사용을 지원합니다.

트리에 달린 양말과 선물은 `components/tree`의 HTML 버튼입니다. 트리 하나에 최대 30개의 이야기가 달리며, WebGL을 사용할 수 없어도 같은 장식을 선택해 이야기를 읽을 수 있습니다. 엔진 코드는 로그인/설문 경로에서 내려받지 않습니다.

## 초대장 소비자

`invitation.ts`는 같은 세션에 `effects/envelope.ts`를 조합합니다. `start`는 ready 이후 도착을 시작하며 `depart`는 마지막 활성 프레임 시각부터 출발합니다. phase callback은 단계가 바뀔 때만 호출합니다. reading callback에서 세션을 멈추고, 출발에서 다시 재생합니다. 완료 callback은 React의 단일 이동 함수로 연결합니다. 준비 제한은 3초이며, 셰이더 준비 후 실제 첫 프레임을 기다리는 별도의 3초 제한이 있습니다. 숨겨진 탭이나 화면 밖에서 대기한 시간은 제외합니다. 출발 제한은 2.5초이며, 입장 요청 이후 탭을 숨기면 즉시 이동을 마칩니다. 봉투는 재생 중 경과한 시간을 사용하고 눈·트리의 프레임 간격 제한은 기존대로 유지합니다.

`invitation-layout.ts`는 실제 DOM 편지 크기를 직교 카메라 좌표로 바꿉니다. 읽기에서는 3D 종이 면을 숨기고 같은 위치의 HTML 표면으로 전환합니다. 리사이즈 때 서비스가 현재 elapsed 값으로 효과를 한 번 갱신해 정지된 장면도 새 앵커에 맞춥니다. 기존 서비스의 공개 API·DPR·가시성·컨텍스트 종료 정책은 유지합니다.

봉투 효과는 자체 geometry/material/light만 소유하고 정리하며 DOM·인증·라우터를 참조하지 않습니다. 소비자 컴포넌트는 늦은 import/ready를 무시하고 timeout·실패·언마운트에서 세션을 해제합니다. 정적 모드와 동작 줄이기에서는 효과 모듈 자체를 불러오지 않습니다. 설정상 재생이 허용된 상태에서 준비에 실패하면 짧은 CSS 봉투 효과로 읽기를 엽니다. 대체 화면을 선택한 뒤에는 늦은 ready가 재생을 되살리지 않습니다. 기기별 원인을 구분하는 절차는 [휴대폰 모션 진단](../../docs/MOTION-TROUBLESHOOTING.md)을 참고하세요.

## 스프링 공책

`pageCurl.ts`는 보이는 본문을 캡처한 canvas 한 장을 공용 세션에 전달한다. 앞뒷면은 52×6 분할 geometry를 공유한다. 앞면은 sRGB 본문 텍스처를 사용하고 뒷면은 아이보리 단색이다. 캡처나 GPU 준비를 기다리는 동안 실제 내용의 DOM 복제본이 같은 자리를 채운다. 이 소비자만 일회용 canvas를 사용하므로 종료 시 자체 컨텍스트를 반환한다. 읽기 상태에서 페이지 컬 세션은 없다. 동작과 검증 자료는 [스프링 공책](../../docs/SPIRAL-NOTEBOOK.md)에 있다.
